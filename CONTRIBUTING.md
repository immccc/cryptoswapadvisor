# Contributing to Crypto Swap Advisor Bot

Thank you for your interest in contributing! This document outlines the rules and expectations for contributing to this project.

## Workflow

### Pull Requests Only

All changes must go through Pull Requests. Pushing directly to `main` is strictly restricted and forbidden.

### Pull Request Structure

Every PR must include a comment following the **WHAT - WHY - HOW** structure:

- **WHAT**: Describe the problem the change tries to solve and what the PR contains.
- **WHY**: Explain why this change is needed and why it should be merged.
- **HOW**: Detail how the problem is mitigated in the change proposal and what approach was taken.

### Commit Responsibility

The committer is responsible for their changes and their impact on quality, performance, or stability of the product, regardless of whether the content is AI-generated or not.

## AI-Generated Content

AI tools are allowed for contributing, but with the following requirement:

**Any content added with AI must be enclosed by comments** to facilitate better reviewing. For example:

```python
# AI-GENERATED-START
def calculate_swap_ratio(a, b):
    return a / b
# AI-GENERATED-END
```

This rule can be bypassed, but doing so honestly is expected. Hiding AI-generated content will be considered a malicious attack rather than an oversight. Honest, transparent use of AI is welcomed and encouraged.

## Code Standards

- Follow existing code style and conventions
- Write tests for new functionality
- Ensure the codebase passes linting and type checking before submitting

## Getting Started

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes
4. Submit a Pull Request with the WHAT - WHY - HOW comment
5. Wait for review and address any feedback

Thank you for contributing!
